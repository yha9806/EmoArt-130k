# Track1 Full1000 Human Review Pack 20260608

这个目录旁边的 `full1000_human_review_pack_20260608.zip` 是 Track1 全量人工审核包。

## 内容

- `track1_full1000_human_review_zh.html`: 离线中文审核页面。
- `assets/`: 1000 个样本的 current / v3 / B80 / B120 / B160 压缩 WebP 对照图，共 5000 张。
- `track1_full1000_human_review_template.csv`: 可填写的人工审核模板。
- `track1_full1000_seeded_risk_notes.csv`: 当前已知人工预标问题。
- `README_human_review_zh.md`: 合作者审核手册。

- `track1_0049`: 右侧枪托/武器接触逻辑问题。
- `track1_0080`: 脚的朝向/站姿逻辑问题。

## 使用方式

解压 zip 后用浏览器打开 `track1_full1000_human_review_zh.html`。页面支持搜索、P0/P1 筛选、人工预标筛选、本地记录和 CSV 导出。

这个包只用于人工审核，不会修改当前 Track1 champion submission。
