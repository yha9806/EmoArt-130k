# AffectiveArt Track2 人工复审协议

目标不是让人评员“重新理解整张画的全部情绪”，而是让人评员对模型冲突样本做可重复的二选一仲裁。

## 核心原则

1. 不从 12 类里自由选标签。只在页面给出的候选标签之间选择。
2. 先判定 valence 和 arousal，再判 emotion。
3. 只按画面证据判断，不按模型理由、caption 文采、艺术家名气判断。
4. 如果两个候选都说得通，但没有明显证据推翻当前候选，选择当前 guarded 版本。
5. 如果图像证据不足、文字和图像冲突、或人评员无法解释选择，标记 `hold`。

## 三步判断法

### 1. Valence：正向还是负向？

正向：画面主导感受是安宁、舒适、快乐、繁荣、欣赏、温和亲密。

负向：画面主导感受是痛苦、威胁、冲突、疲惫、厌倦、焦虑、愤怒、挫败。

不要因为颜色暗就自动判负向。传统水墨、版画、老照片式色彩可能是低饱和但仍然平静或满足。

### 2. Arousal：高唤醒还是低唤醒？

高唤醒：动作强、冲突强、危险、骚动、奔跑、打斗、强烈节奏、强烈表情。

低唤醒：静止、冥想、休息、观看、安静风景、仪式性站立、柔和互动。

不要因为构图复杂就自动判高唤醒。复杂场景也可能是平静的叙事或装饰。

### 3. Emotion：只在候选中二选一

先排除 valence/arousal 不匹配的候选。如果两个候选同象限，再看下面的边界。

## 常见边界

`calm / 平静`：静、松弛、安宁、无明显欲望或庆祝。常见于山水、静态肖像、冥想、休憩。

`content / 满足/安适`：不仅平静，还带有“满足、安居、享受、生活圆满”的意味。常见于家庭、宴饮、闲适生活、拥有感。

`glad / 高兴`：有明显喜悦或庆祝，但不一定高能量。需要看到笑意、庆贺、社交愉悦、成功感。

`happy / 快乐`：比 glad 更通用的积极快乐，画面有愉悦、欢快、友好或节庆感。

`excited / 兴奋`：正向高唤醒。画面应有活跃、热闹、节庆、运动、强烈期待。

`aroused / 激发/兴奋`：高唤醒但不一定快乐，可能是激情、震撼、紧张、感官刺激。

`alarmed / 惊恐/警觉`：负向高唤醒，重点是危险、惊惧、警戒。

`annoyed / 恼怒`：负向高唤醒，重点是恼火、不耐烦、冲突姿态。

`frustrated / 挫败/受阻`：负向高唤醒，重点是努力受阻、压抑、挣扎、失败感。

`sad / 悲伤`：负向低唤醒，重点是失落、哀悼、孤独、沉重。

`tired / 疲惫`：负向低唤醒，重点是耗尽、困倦、无力。闭眼不等于疲惫；也可能是平静。

`bored / 厌倦`：负向低唤醒，重点是无聊、冷漠、空转、缺乏兴趣。

## 对当前复审包的推荐策略

Tier A：默认接受 guarded。只检查是否出现明显错误，例如安静山水被判成高唤醒负向，或打斗冲突被判成 calm。

Tier B：抽查即可。若没有明显反证，保留 guarded。

Tier C：必须人工看。按三步法二选一，不能直接听模型。

## 人评输出要求

每个样本只需要一个结果：

- `accept_recommendation`：接受页面推荐。
- `use_base`：选择 Base 标签。
- `use_scaled_desc_v1`：选择 Scaled desc_v1 标签。
- `hold`：无法可靠判断，暂不改。

备注只写一句画面证据，例如：

- “静态山水、无人冲突、低唤醒，选 calm。”
- “水牛顶撞，明显冲突和高唤醒，不能选 calm。”
- “家庭聚集但没有明显庆祝，更像 content/calm，hold。”
